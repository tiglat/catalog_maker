# Архитектура проекта CatalogMaker

Это приложение является плагином (Packer plugin) для программы TotalCommander.

## Технологический стек

* Приложение реализовано как динамически подгружаемая библиотека. Ее интерфейс соответствует требованиями для Packer plugin TotalCommander.
* Язык программирования C++ версии 20
* Используется библиотека STL
* Графический интерфейс пользователя реализован с помощью Win32 API
* Взаимодействие с файловой системой реалзивано с помощью Win32 API

## Состав файлов

- CatalogMaker.cpp
В файле  реализован интерфейс взаимодействия с TotalCommander. Здесь находятся основные точки входа.

- FileList.h 
является реализацией реализацией алгоритмов обработки списка файлов, включая функции сбора мета информации о файлах и папках.

- UIFunc.cpp и UIFunc.h
Содержат функции для работы с графическим интерфейсом пользователя

- CatalogMaker.rc
Содержит описание графического интерфеса пользователя.

- AnsiStringOperations.cpp и AnsiStringOperations.h
Реализация операций по работе с ASCII строками

- WideStringOperations.cpp и WideStringOperations.h
Реализация операций по работе с Unicode строками

- IStringOperations.h
Описание интерфейса для работы со строками

- GlobalVars.cpp и GlobalVars.h
Объявления глобальных переменных, содержащих параметры конфигурации
